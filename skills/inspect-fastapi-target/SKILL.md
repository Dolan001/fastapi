# Inspect FastAPI target

Inspect manifests, application entry points, routers, settings, dependency wiring,
database/session ownership, migrations, authentication, OpenAPI, and tests. Sample
representative domains instead of reading the entire tree. Record confidence,
structure deviations, and conventions that brownfield work must preserve.
