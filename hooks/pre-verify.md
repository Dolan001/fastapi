# Pre-verify

Require a different agent, immutable implementation evidence, and the FastAPI
verification skill. Verification writes evidence only. Require the PRD-to-domain mapping and
independently confirm familiar names, cohesive files, resource/use-case schema/route packages,
and valid router imports and operation IDs after every split.
Reject migration claims based only on `metadata.create_all()`, ownership sourced from request
payloads, required external effects implemented only as in-process background tasks, or API tests
that bypass dependency boundaries.
