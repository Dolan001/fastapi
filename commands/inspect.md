# Inspect

Read the PRD and target without mutation. Detect FastAPI routes, schemas, dependencies,
services, repositories, persistence, migrations, settings, tests, Docker, CI, and API
conventions. Store findings under target `.ai/discovery/`.
For persistence, record PostgreSQL version/driver, engine/pool/session ownership,
Alembic heads, domain tables, constraints, indexes, transaction boundaries, hot query
shapes, query budgets, pagination, and router/OpenAPI conventions.
